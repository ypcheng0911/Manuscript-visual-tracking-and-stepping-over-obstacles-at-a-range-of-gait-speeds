# Coordinated Human Electrocortical Spectral Power Dynamics and Eye Gaze Fixation During Visual Tracking and Stepping Over Obstacles at a Range of Gait Speeds

Code repository accompanying the manuscript (currently awaiting review).

## Overview
This repository contains the analysis code used to process mobile high-density EEG,
eye-gaze tracking, and video-based gait data collected during visually guided walking
and obstacle avoidance in projected virtual reality.

## Repository Structure

| Folder | Description |
|---|---|
| `EEG_data_cleaning/` | Preprocessing and artifact rejection pipeline for high-density mobile EEG |
| `Eye_tracking_data_processing/` | Eye-gaze fixation extraction and alignment with gait events |
| `Computer_vision_model/` | Video-based tracking/pose estimation used for obstacle-stepping kinematics |
| `Figure_generation/` | Scripts to reproduce the manuscript's main and supplementary figures |
